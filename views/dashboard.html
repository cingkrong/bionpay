Panduan Pengambilan Token ShopeePay
1. Login ke Shopee Merchant Web
Kunjungi portal shopeepay.shopee.co.id/merchant pada browser komputer Anda dan login dengan akun toko ShopeePay Anda.
2. Buka DevTools (F12)
Tekan tombol F12 atau klik kanan > Inspect, lalu pilih tab Network.
3. Filter Request "get-transaction-list"
Buka menu Transaksi di portal merchant. Di tab Network, cari request yang bernama get-transaction-list.
4. Salin Token dari Payload / Request Body
Klik request tersebut, buka sub-tab Payload atau Request, cari properti metadata.token (berformat string panjang diawali dengan B:...). Salin dan tempel ke form di sebelah kiri.
💡 Notifikasi Telegram Otomatis:
Jika token ShopeePay mendekati masa kadaluarsa atau terjadi error otentikasi, BionPay dapat mengirimkan alert instan ke Telegram Anda. Cukup isi TELEGRAM_BOT_TOKEN dan TELEGRAM_CHAT_ID di file .env.

Panduan Integrasi Cepat (Quick Integration)

1. Membuat Transaksi QRIS Dinamis

Panggil endpoint POST /create-qris dengan menyertakan header x-api-key dan payload nominal pembayaran.

curl -X POST "{{ORIGIN}}/create-qris" \
  -H "Content-Type: application/json" \
  -H "x-api-key: {{API_KEY}}" \
  -d '{"amount": 50000, "order_id": "ORDER-991", "callback_url": "https://toko.com/webhook"}'

2. Contoh Kode Node.js (Fetch)

const response = await fetch('{{ORIGIN}}/create-qris', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'x-api-key': '{{API_KEY}}'
  },
  body: JSON.stringify({
    amount: 50000,
    order_id: 'INV-1029'
  })
});
const { data } = await response.json();
console.log('Buka checkout:', data.qris_url);

3. Webhook Notifikasi Otomatis

Ketika pelanggan berhasil membayar, gateway akan secara otomatis mengirimkan HTTP POST ke URL callback toko Anda dengan payload:

{
  "event": "payment.success",
  "qris_id": "abc12345",
  "trx_id": "TRX-ABC12345",
  "order_id": "INV-1029",
  "amount": 50000,
  "payer_issuer": "GoPay / BCA",
  "status": "PAID",
  "timestamp": 1729080000000
}
