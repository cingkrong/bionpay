Panduan Integrasi Cepat (Quick Integration)

1. Membuat Transaksi QRIS Dinamis

Panggil endpoint POST /create-qris dengan menyertakan header x-api-key dan payload nominal pembayaran.

curl -X POST "{{ORIGIN}}/create-qris" \
  -H "Content-Type: application/json" \
  -H "x-api-key: {{API_KEY}}" \
  -d '{"amount": 50000, "order_id": "ORDER-991", "callback_url": "https://toko.com/webhook"}'

2. Contoh Kode Node.js (Fetch)

const response = await fetch('{{ORIGIN}}/create-qris', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'x-api-key': '{{API_KEY}}'
  },
  body: JSON.stringify({
    amount: 50000,
    order_id: 'INV-1029'
  })
});
const { data } = await response.json();
console.log('Buka checkout:', data.qris_url);

3. Webhook Notifikasi Otomatis

Ketika pelanggan berhasil membayar, gateway akan secara otomatis mengirimkan HTTP POST ke URL callback toko Anda dengan payload:

{
  "event": "payment.success",
  "qris_id": "abc12345",
  "trx_id": "TRX-ABC12345",
  "order_id": "INV-1029",
  "amount": 50000,
  "payer_issuer": "GoPay / BCA",
  "status": "PAID",
  "timestamp": 1729080000000
}
